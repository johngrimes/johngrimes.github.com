Profile

I design and build software and standards that make health data usable for analysis. My work combines FHIR, clinical terminology and large-scale data processing. I created Pathling, an open-source toolkit for FHIR analytics, and I co-lead the HL7 SQL on FHIR specification.

I have worked in Australian digital health since 2010, including as lead architect of the National Clinical Terminology Service and on the requirements for My Health Record. Before that I built and ran web products. I write the specification, the code and the tests, and I pay close attention to the details that make a tool reliable and pleasant to use.

Selected work

Pathling

2018 – present

Creator and technical lead, CSIRO · pathling.csiro.au

An open-source toolkit for analysing FHIR data with clinical terminology, built on Apache Spark: libraries for Python, R, Java and Scala, a FHIR server and a command line tool. Queries can apply subsumption and concept map translation across whole datasets.

  • Principal author, with more than 5,000 commits since the first in December 2018.
  • Python package downloads grew from about 3,000 to about 20,000 a month between mid 2025 and mid 2026.
  • Used by research and health organisations including the University of Queensland, SickKids in Toronto, the Murdoch Children’s Research Institute and the Bavarian Cancer Research Center.
  • The query engine behind CSIRO work on FHIR-to-OMOP transformation, data quality assessment and agent-based analytics.

Java · Scala · Apache Spark · Delta Lake · Python · FHIRPath · Kubernetes

SQL on FHIR

2023 – present

Project co-lead, HL7 International · sql-on-fhir.org

An HL7 specification for defining portable, tabular views of FHIR data using FHIRPath. A view written once runs unchanged on any conforming engine, from DuckDB on a laptop to a Spark cluster.

  • Took the specification to its September 2026 HL7 ballot, including new operations for running and exporting views and SQL queries.
  • Thirteen independent implementations, including those from Google, Health Samurai, Medplum, NCQA and SAS, are tested against a shared conformance suite.
  • Most active contributor to the specification, and first author of the paper that describes it.
  • Wrote an implementation that compiles views to T-SQL for Microsoft SQL Server.

FHIRPath · SQL · TypeScript · DuckDB · FHIR IG Publisher
